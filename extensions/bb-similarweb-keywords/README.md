# BB Similarweb Keywords

在 `sim.3ue.co` 导出 CSV。
点浏览器工具栏里的扩展图标，不会在页面上出现浮层。

## 网站关键词表

- 改页数，默认前 5 页；总页数不足 5 页时默认全部
- 改文件名，默认是 `{域名}-organic-keywords.csv`
- 从第 1 页开始抽，直接存到下载目录

## 网站表现

停在网站表现页时，同一按钮改为抽取卡片数据：

- 流量与互动：总访问量、设备分发、全球排名、国家/地区排名、行业排名
- 参与度概览
- 随着时间的访问（按月）
- 热门国家与地区
- 流量来源与渠道
- 自然搜索、热门自然非品牌搜索词
- 付费搜索、外链、出站流量、导出广告、社交、显示广告

没有结果的板块会留空，并在备注里写「没有结果」。
流量占比的变动会带上涨跌方向。

## 着陆页

停在着陆页时，导出当前域名当前页的着陆 URL。
测试阶段先抽当前域名第 1 页。
每条着陆页会再抽：

- 点击量趋势，按「天」
- 对应关键词，前 5 页

点击量拆成点击量和点击量占比。
变动带上涨跌方向。
导出为一个 zip：里面是多个 CSV。
汇总一份，每个域名的趋势一份、关键词一份。

默认文件名是 `{域名}-website-performance.csv`，也可以改成自定义名字。
CSV 用长表：板块、项目、指标、数值、变动、备注。

## 注意

只读页面已经渲染出来的内容。
关键词表会点页面自己的下一页。
不要一次抽过多页，以免触发平台限制。
